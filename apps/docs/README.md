# Docs workspace

This workspace is the original Turborepo starter page. It is kept as a sandbox;
the maintained project documentation is [docs/DEVELOPMENT.md](../../docs/DEVELOPMENT.md)
and the [root README](../../README.md).

`npm run --workspace docs dev` starts the sandbox on port 3001. It is not part of
the production Docker stack. Changes to product behavior belong in `apps/web`.
