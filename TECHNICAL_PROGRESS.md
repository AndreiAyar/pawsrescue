# Cat Matching Technical Progress

Updated: June 12, 2026

## Current Pipeline

1. A pretrained Faster R-CNN ResNet-50 FPN v2 detector analyzes each photo.
2. The detector returns bounding boxes, confidence scores, and numeric COCO class IDs.
3. The service selects the highest-confidence box whose class ID maps to `cat`.
4. The box is expanded by configurable padding and cropped from the photo.
5. DINOv3 ViT-L creates one embedding for the cat crop and one for the original photo.
6. The normalized embeddings are combined with an 80% crop and 20% original weighting.
7. PostgreSQL pgvector ranks compatible embeddings using cosine distance.

The detector does not interpret an English prompt. It was pretrained with labeled examples
from the COCO dataset and learned a fixed set of object categories. The word `cat` in the
code is used only to find the detector's numeric cat class ID.

## Implemented Changes

- Standardized matching on `facebook/dinov3-vitl16-pretrain-lvd1689m`.
- Added automatic cat detection and padded cat-focused cropping.
- Added original-image fallback when no confident cat is detected.
- Preserved the full 1024-dimensional DINOv3 ViT-L embedding.
- Migrated the database vector column from 768 to 1024 dimensions.
- Changed ranking from Euclidean distance to cosine distance.
- Restricted comparisons to records generated by the exact same pipeline version.
- Changed the displayed percentage to cosine similarity: `(1 - cosine distance) * 100`.
- Added `npm run --workspace api embeddings:rebuild` for regenerating stored vectors.

  their image files were not available locally, and 0 failed.

## Limitations

- Similarity is a candidate-ranking score, not proof that two photos show the same cat.
- DINOv3 is a general visual model and is not yet fine-tuned for individual cat identity.
- AI-generated or edited photos may alter identity markings.
- Listings skipped during backfill need their source photos restored before embeddings can
  be regenerated.
- Production should cache the detector and DINOv3 weights and allow enough memory for both
  models.

## Next Accuracy Step

Collect labeled same-cat and different-cat photo pairs, then fine-tune a metric-learning
model. Multiple enrollment photos per lost cat should also be stored and compared instead
of relying on a single averaged reference image.
