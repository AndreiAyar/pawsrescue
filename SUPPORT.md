# Getting help

For setup, start with [DEVELOPMENT.md](docs/DEVELOPMENT.md). For a reproducible
bug or a proposed improvement, [open an issue](https://github.com/AndreiAyar/pawsrescue/issues).
Include your operating system, runtime versions, command, and redacted error.

PawsRescue is maintained in spare time. There is no support SLA or emergency
response service. Posting an animal here does not notify shelters, vets, or
local authorities, and photo similarity does not confirm identity.

For sensitive security issues, follow [SECURITY.md](SECURITY.md).
